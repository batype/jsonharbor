标题：每天一个开源小项目 002：JSON 格式化之后，19 位 ID 还在吗？

做了一个本地 JSON 工作台：JSON Harbor · 拾码。

支持格式化、压缩、递归排序、中文错误定位、树浏览、路径提取和结构对比。特别保留数字原文：9223372036854775807、2.370、-0 都不会被格式化偷偷改写。

纯前端、不上传输入，不加账号；支持亮暗模式。相同核心还可以在 Node CLI / API 中用，AI 也有可安装 skill。

体验：https://batype.github.io/jsonharbor/
源码：https://github.com/batype/jsonharbor

15 秒演示：粘贴含长 ID 的数据 → 格式化 / 压缩 → 按路径提取 ID → 切到对比，展示新增和修改。
