# 网页代码对比更新

## 范围

将网页原先只列出字段变更的对比区升级为代码审阅工作台：全宽左右并排、合并视图、行号、红绿背景、行内修改高亮、相同行折叠和展开、差异分组跳转、规范化 / 原文模式、两侧交换。字段报告保留独立入口，原 CLI / API、数字解析引擎及 npm 包版本没有变化。

对比按行进行，键顺序变化也会出现在代码视图中；字段视图仍忽略对象键顺序。规范化模式保留数字和字符串原文，只统一缩进。原文模式允许正在编辑的无效 JSON；此时不生成字段报告。

## 验证

- `npm test`：13 组通过。原有 8 组引擎与 CLI 集成回归继续通过；新增行级对齐、精确数字、规范化 / 原文、上下文折叠、200 组随机文本完整重建与最小编辑数比对、大差异降级、UTF-16 字符高亮、Worker 字段 / 代码独立结果验证。
- 浏览器：示例显示 3 组代码变化、+4 / −3 行，字段报告仍为新增 1、删除 0、修改 3。已实际切换并排 / 合并 / 字段、跳转下一处、展开相同行。
- 重复键保留所有成员，代码视图仍高亮完整 19 位 ID；字段报告提示有歧义并禁用导出。HTML 字符串作为文本显示。
- 无效 JSON 在规范化模式报错；切换原文模式后可正常比较，并显示字段对比暂不可用。
- 1000 行输入触发明确的大差异降级提示，结果分段显示；下一段从对齐行 401 开始。
- 已检查 1280 × 900 桌面和 390 × 844 手机视口，页面无横向溢出。各代码列允许水平滚动，手机可使用合并视图。

## 边界

代码每侧最多 10000 行，单页最多 400 个对齐行。行内高亮标记共同前后缀之间的变化范围，不声称逐词最小编辑；超过 4000 字符的长行保留行级高亮。大编辑距离或工作量超限时保留公共首尾，并把中间完整范围显示为替换。字段报告仍最多 500 处，代码和字段数量不必相同。

## 独立页面流程（2026-10-21）

对比从主页内嵌视图迁移为独立 `diff.html`，主页导航、醒目入口和原对比位置均提供新标签页链接，原主页输入不受影响。直接访问或刷新这个地址也能正常加载。Diff 页初始为空白双输入；载入示例、交换或修改文本后，等待用户点击「开始对比」，不自动执行。新增返回主页入口，亮暗主题继续共享。

主页与 Diff 页各自持有输入和 Worker 会话，仅复用安全文本渲染、解析及代码对比逻辑。输入不经 URL、持久化存储或网络传递；CLI / API 不变。验证包括主页新标签页入口及输入保留、独立页空输入提示、点击前无结果、手动对比长 ID / 小数、字段报告复制、主页格式化和两标签键盘切换回归，以及手机布局。
